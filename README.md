# 🎰 赌城大冒险（德州 · 牛牛 · 打怪）

一个纯前端、零依赖的休闲小游戏合集，挂在 GitHub Pages 上即可玩。包含三大模块：

- **主界面**：角色面板（金币 / 攻击 / 生命 / 幸运）、**打怪爆金币**、**兑换码**入口。
- **赌场**：🂡 德州扑克（5 级牌桌、每桌 9 人含 8 个 AI、翻牌前/翻牌/转牌/河牌四轮下注）与 🐂 斗牛牛（抢庄制、多人机）双游戏。
- **装备**：用金币升级武器（攻击）、护甲（生命）、幸运符（金币爆率）。

## 玩法

### 德州扑克（RPG）
- 初始金币 200，选桌入座（每桌 9 人，含 8 个 AI）。赢牌赚金币。
- 四轮下注（翻牌前 / 翻牌 / 转牌 / 河牌），**每局结束后需点击「下一局」才继续**。
- 金币归零就回主界面**打怪爆金币**，再到装备页升级战力。

### 斗牛牛（抢庄）
- 你与若干电脑玩家同处一桌，发牌后**看牌抢庄**，抢庄者中牌最大者坐庄。
- 闲家与庄家比牌结算：牛1~6 赢 1 倍、牛7~9 赢 2 倍、牛牛 3 倍、五花牛/炸弹 4 倍、五小牛 5 倍；输则扣注，平局退还。

### 兑换码
- 在主界面输入兑换码可领取奖励（默认码见 `index.html` 顶部 `REDEEM_CODE`，可自改）。
- 提示：兑换码请使用中性、非针对任何个人的词语。

## 运行

- **在线**：直接用浏览器打开 GitHub Pages 链接即可。
- **本地**：双击 `index.html`，或启动一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 技术

单文件 `index.html`，HTML + CSS + 原生 JavaScript，无任何外部依赖或构建步骤。进度（金币 / 装备 / 兑换记录）保存在浏览器 `localStorage`。

> ⚠️ 本游戏仅使用虚拟筹码，不涉及任何真实货币赌博。

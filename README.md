# 🐂 牛牛小游戏（单挑庄家）

一个纯前端、零依赖的「斗牛牛」纸牌小游戏，单人挑战电脑庄家，挂在 GitHub Pages 上即可玩。

## 玩法

- 你与庄家各发 5 张牌。
- 点数：A=1，2~10=面值，J/Q/K=10。
- 从 5 张中找出 3 张点数和为 10 的倍数（即「有牛」），剩下 2 张点数和的个位数就是你的「牛数」；个位为 0 即为 **牛牛**（最大）。
- 比大小：牛牛 > 牛9 > … > 牛1 > 无牛；同等级比最大单牌（K 最大，♠>♥>♣>♦）。
- 特殊牌型：五花牛 / 炸弹 / 五小牛。

### 赔率

| 牌型 | 赢的倍数 |
|------|---------|
| 牛1~6 | 1× |
| 牛7~9 | 2× |
| 牛牛 | 3× |
| 五花牛 / 炸弹 | 4× |
| 五小牛 | 5× |

输则扣下注额，平局退还。

## 运行

- **在线**：直接用浏览器打开 GitHub Pages 链接即可。
- **本地**：双击 `index.html`，或启动一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 技术

单文件 `index.html`，HTML + CSS + 原生 JavaScript，无任何外部依赖或构建步骤。

> ⚠️ 本游戏仅使用虚拟筹码，不涉及任何真实货币赌博。
